# 🍺 啤酒风格识别分类项目汇报

> 基于3万+啤酒数据的多模态深度学习分类系统

---

## 一、项目概述

### 1.1 项目背景

随着精酿啤酒市场的快速发展，啤酒风格种类日益增多。本项目旨在利用机器学习技术，基于啤酒的物理属性和风味描述，实现啤酒风格的自动识别与分类。

### 1.2 项目目标

- **自动标注**：为大量未标注的啤酒数据自动分类
- **智能推荐**：根据用户偏好推荐相似风格啤酒
- **市场分析**：分析啤酒市场的风格分布趋势

### 1.3 技术栈

| 模块 | 技术选型 |
|------|----------|
| **数据处理** | Python, JSON, CSV |
| **传统ML** | XGBoost, Scikit-learn |
| **深度学习** | PyTorch, HuggingFace Transformers, BERT |
| **可视化** | Matplotlib, Seaborn |

## 四、模型方案对比

### 4.1 三种模型方案

#### 方案A：XGBoost + 数值特征

**特征输入：** abv, ibu, srmId, glasswareId, availableId

**架构：**
```
数值特征 → 标准化 → XGBoost → 分类输出 (171类)
```

**优势：**
- 训练速度快（约30秒）
- 可解释性强（特征重要性可分析）

**劣势：**
- 仅使用5个数值特征，信息量不足
- 无法捕捉文本描述中的语义信息

---

#### 方案B：BERT + 文本特征

**特征输入：** description 文本描述

**架构：**
```
文本描述 → BERT编码器 →<[BOS_never_used_51bce0c785ca2f68081bfa7d91973934]> token → 分类层 (168类)
```

**优势：**
- 利用预训练BERT的语义理解能力
- 能捕捉"柑橘香气"、"麦芽味"等关键语义特征

**劣势：**
- 训练时间较长（每轮约2.5分钟）
- 忽略了物理属性信息

---

#### 方案C：多模态融合模型（推荐）

**特征输入：** 文本描述 + 5个数值特征

**架构：**
```
┌─────────────────────────────────────────────────────────┐
│                    输入层                               │
│  ┌───────────────┐                    ┌──────────────┐  │
│  │ 文本分支:     │                    │ 数值分支:    │  │
│  │ description   │                    │ abv, ibu...  │  │
│  └───────┬───────┘                    └──────┬───────┘  │
│          │                                   │          │
│          ▼                                   ▼          │
│  ┌───────────────┐                    ┌──────────────┐  │
│  │ BERT编码器    │                    │ 标准化       │  │
│  │ (768维)       │                    └──────┬───────┘  │
│  └───────┬───────┘                           │          │
│          │                             ┌─────▼──────┐  │
│          │                             │ 数值MLP    │  │
│          │                             │ (32维)     │  │
│          │                             └─────┬──────┘  │
│          └─────────────┬─────────────────────┘          │
│                        ▼                                │
│              ┌──────────────────┐                        │
│              │  特征拼接层       │                        │
│              │ (768+32=800维)   │                        │
│              └────────┬─────────┘                        │
│                       ▼                                 │
│              ┌──────────────────┐                        │
│              │  融合层MLP       │                        │
│              │ (800→256→128)   │                        │
│              └────────┬─────────┘                        │
│                       ▼                                 │
│              ┌──────────────────┐                        │
│              │  分类层          │                        │
│              │ (128→168)       │                        │
│              └──────────────────┘                        │
└─────────────────────────────────────────────────────────┘
```

**优势：**
- 融合文本语义和物理属性
- 融合有协同增益（1+1>2）
- 性能最优

**劣势：**
- 架构复杂度最高
- 训练时间最长（约25分钟）

### 4.2 模型性能对比

| 指标 | 方案A (XGBoost) | 方案B (BERT) | 方案C (融合) | 最佳方案 |
|------|-----------------|--------------|--------------|----------|
| **准确率** | 23.14% | 46.14% | **51.12%** | 方案C ✅ |
| **Macro-F1** | 5.21% | 11.08% | **17.57%** | 方案C ✅ |
| **Weighted-F1** | 16.59% | 37.48% | **45.84%** | 方案C ✅ |
| **训练时间** | ~30秒 | ~7分钟 | ~25分钟 | - |

### 4.3 性能提升分析

**方案C vs 方案A：**
- 准确率提升：+27.98%
- Macro-F1提升：+12.36%

**方案C vs 方案B：**
- 准确率提升：+4.98%
- Macro-F1提升：+6.49%

**关键发现：**
1. **文本特征是主力**：贡献了约90%的分类能力
2. **数值特征有补充作用**：提供了约10%的额外信息
3. **融合有协同增益**：1+1>2的效果

## 六、关键发现与结论

### 6.1 数据层面发现

1. **类别不平衡严重**：
   - 最大类别（美式IPA）占比11.7%
   - 最小类别样本数不足10
   - 导致Macro-F1普遍偏低

2. **数据缺失问题**：
   - 约25%的啤酒缺少描述文本
   - 约15-30%的数值特征缺失
   - 需要更完善的数据收集策略

3. **特征价值分析**：
   | 特征类型 | 对分类的贡献 | 原因 |
   |----------|------------|------|
   | 文本描述 | ~90% | 包含风味、工艺等关键语义 |
   | 数值特征 | ~10% | 物理属性区分度有限 |

### 6.2 模型层面发现

1. **文本语义是关键**：
   - 啤酒风格更多由"风味描述"决定
   - 仅凭abv/ibu等物理属性难以区分

2. **多模态融合有效**：
   - 方案C相比方案B提升5%
   - 证明数值特征有补充价值

3. **细粒度分类困难**：
   - 168个类别，平均每类仅约134样本
   - 部分风格差异极小，难以区分

### 6.3 业务启示

1. **对推荐系统的意义**：
   - 基于风格相似度的推荐更可靠
   - 需结合用户偏好的多维特征

2. **对市场分析的意义**：
   - 美式IPA占据绝对主导
   - 特种啤酒、酸啤是增长品类
